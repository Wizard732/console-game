# Console Game (Python)

A simple console-based game written in Python.

## Features
- Player creation with name, age, and preferences
- Basic scoring system
- Game-related quiz logic
- Object-Oriented Programming (classes)

## Technologies
- Python 3
- Console (CLI)

## How to run
1. Make sure Python 3 is installed
2. Run the program:
   python main.py

## Purpose
This project was created for learning Python basics:
- variables
- conditions
- functions
- classes
- simple logic
